Write a message, attach a file, and get a single-use link. Everything is encrypted with AES-256-GCM before it leaves your device, and the key stays in the link fragment the server never receives.

  • ✓ Zero-knowledge storage — the server only ever holds ciphertext.
  • ✓ Single retrieval — the message is deleted as soon as it is read.
  • ✓ Automatic expiry — unread messages disappear after one hour.

Optional extras: file attachments up to 1 MB, credential fields, and email OTP protection.
